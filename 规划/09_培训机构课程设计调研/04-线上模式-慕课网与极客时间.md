# 04 · 线上模式：慕课网 与 极客时间

> 线上分两种：**录播体系课/就业班**（慕课网，自主安排）和**直播训练营**（极客时间，有班主任督学）。
> 慕课网 AI Agent 就业班：<https://class.imooc.com/learnservice/llmappdev> ｜ 极客时间训练营：<https://u.geekbang.org/>

## 一、慕课网：录播体系课 + 就业班

### AI Agent 全栈开发工程师（就业班）
| 指标 | 官方口径 |
|---|---|
| 课程内容 | **20 周** |
| 教学服务期限 | **10 个月** |
| 手敲代码量 | **约 70000 行** |
| 企业级项目 | **2 个大型项目** |
| 实操案例 | **16+ 个** |

- 定位："一课具备商业级大型复杂项目能力"，对标就业；
- 借鉴点：**把"代码量 / 项目数 / 案例数"量化成硬指标**，并把"内容周期（20 周）"和"服务周期（10 个月）"分离——内容学完后仍保留答疑/复习服务。

### LLMOps 应用平台特训营（8 阶段，已完结）
1. **平台基石搭建**：LLMOps 架构设计、基础聊天机器人；
2. **商业级聊天机器人**：记忆、自动联网、企业知识库；
3. **平台可视化 + 安全 + 性能优化 + 开放 API**；
4. **平台扩展**：通用型、支持多 LLM 接入；
5–8. 进阶的 Agent / 多智能体 / 部署运维等（第三方页未完整列全）。

### 其他相关课程
- 《LangChain + LangGraph + MCP + 大模型，打造编程智能体》：章节很细，含"AI 编程智能体项目规划 + 多轮对话"完整实战；
- 《AI Agent 从 0 到 1 定制开发（全栈/全流程）》：单 Agent → 多 Agent 协作、RAG、LangGraph 可视化、A2A 协议，打通需求→架构→提示词→开发→评估，**在线 IDE 教学 + 附赠 API**。

> 慕课模式关键词：**在线 IDE、可量化代码量、项目+案例双轨、长服务期**，适合有自制力、想碎片化学、预算有限的人。

## 二、极客时间：直播/训练营模式

代表训练营（定期开班，配班主任/社群/作业）：
- **AI Agent 全栈工程师训练营**（尹会生）：从传统开发走向 AI 应用开发（如第 2 期 10 月 20 日开课）；
- **企业级 Agents 开发实战营**：随报随学；
- **AI 大模型应用开发实战营**；
- **多模态 Agent 开发实战营**：全模态技术集成 + 工程化落地。

服务机制：开课后 7 天内可退款、支持分期、可开发票；有督学和班级社群。

> 训练营本质 = **线上的内容 + 线下式的督学**：比纯录播多了节奏约束和同伴压力，比线下便宜且不脱产，适合"知道该学但管不住自己"的在职/在校者。

## 三、线上 vs 线下：怎么选

| 维度 | 慕课网（录播就业班） | 极客时间（训练营） | 线下机构 |
|---|---|---|---|
| 时间 | 完全自主 | 跟着开班节奏 | 脱产固定作息 |
| 督学强度 | 弱（靠自己） | 中（班主任/社群） | 强（面授+班级） |
| 实践 | 在线 IDE + 量化代码量 | 项目作业 + 点评 | 实训机房 + 分组实战 |
| 单价 | 较低 | 中 | 高（1.6–2.8 万） |
| 适合 | 自律、预算低 | 需轻督学、在职 | 零基础转行、需强推 |

## 四、可直接偷走的设计

1. **量化交付指标**：明确"手敲 X 行代码、N 个项目、M 个案例"，让学习成果可衡量（慕课网）；
2. **内容期与服务期分离**：20 周内容配 10 个月服务，给复习和答疑留窗口（慕课网）；
3. **在线 IDE + 附赠 API**：把环境和算力门槛降到最低，打开浏览器就能练（慕课网）；
4. **训练营做"轻督学"**：班主任 + 作业 + 社群 + 退款机制，用服务设计弥补线上自律不足（极客时间）；
5. **多产品线覆盖深浅**：从单课、专项到就业班/训练营，按预算和目标分层售卖。

## 五、给你的取舍建议

- 你是西电在校、有编程基础、预算敏感：**优先免费资料（08 分类的厦大/B站 + LangChain Academy）**；
- 若想花钱买"结构化 + 项目陪跑"，线上**训练营/就业班性价比高于线下**，且不用脱产；
- 线下 2 万级课程，只有在你需要**强制作息、GPU 机房和校招就业渠道**时才划算；
- 无论哪条路，最终都要回到"**做出 1–2 个能演示、能进 GitHub 的 Agent 项目**"，这是线上线下共同的真正交付物。
