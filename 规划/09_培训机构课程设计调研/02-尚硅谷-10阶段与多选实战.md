# 02 · 尚硅谷：10 阶段与"多行业选一"实战模式

> 学科名 **《AI 全能开发 / 智能体（Agent）开发》**，线下面授 + 海量免费视频双轨。
> 官方课程页：<http://m.atguigu.com/aicoding/> ｜ Agent 专题：<http://m.atguigu.com/agent> ｜ 免费视频平台（谷粒学苑）：<https://www.gulixueyuan.com/>

## 一、最值得抄的两个设计

1. **"多行业 N 选一"实战模板**：同一套技术框架，给出 5–6 个垂直行业版本，学员**任选一个独立完成**——既保证教学可复用、评审标准化，又让每个人的作品有差异化（避免全班雷同）；
2. **把 Harness / Loop 作为独立工程模块**：不只教 LangChain API，而是讲**管控框架工程（Harness Engineering）**和**任务循环工程（Loop Engineering）**，教学深度和本库"读 Agent 源码"的路线高度一致。

## 三、阶段三的工程深度（含金量最高）

- **智能体架构**：提示词、Agent 构成、工具配置、规划执行、记忆机制、MCP、Skill、Function Call；
- **Harness Engineering（管控框架）**：记忆分层管理、技能生命周期、权限与生命周期管控；
- **Loop Engineering（任务循环）**：Think-Act-Observe 循环、任务容错回滚、异常重试、自我修正的执行链路；
- **多智能体设计模式**：协作范式、消息总线、角色划分、通信编排与冲突处理；
- **工程化**：Trace 可观测性、RAGAS/RAGA 评测体系、RAG 典型问题调优、多模型服务（向量/重排序/推理）拆分部署。

## 四、项目池与"多选一"实战设计

**带完整方案的示范项目**
- **掌柜智库（RAG 知识库）**：LangGraph 可插拔 RAG 工作流，MinerU+OCR 解析图文 PDF，Milvus + 稀疏检索，高级切片、HyDE、BGE-Rerank，RAGAS 全链路评测，面向设备售后场景；
- **智数归因平台（掌柜问数）**：DataAgent + AttributionAgent，NL2SQL 自助取数 + 多模型智能归因，FastAPI/AsyncIO，Qdrant/ES，React + ECharts 可视化；
- 另有市场罗盘、工程调研助手、商城风控、万应助手、自动化漏洞挖掘、ETL-Agent、企业合同审批 Agent 等。

**"多选一"实战（学员独立完成）**
- RAG 知识库五选一：好医（医疗）/ 伴学（教育）/ 倾听（音频）/ 金融 / 美途（文旅）智库；
- 智能客服五选一：尚医 / 知学 / 倾听 / 金融 / 美途助手；
- 全栈平台六选一：美途旅行 / 好房易租 / 倾听FM / 云尚课堂 / 谷德家政 / 好医在线。

> 每个"选一"都配套明确的**学习目标清单**（架构设计、框架编排、调优、评测、工程实践 5 条），学员对照目标自测，评审有统一标尺。

## 五、实践与就业机制

- 项目官方定位"**来源于企业真实项目、流程齐全**"，强调入职后可直接套用；
- 阶段式**考试（考试一/二/三）**卡阶段质量，过了才进下一阶段；
- 就业护航：复习对标招聘、简历手把手、1V1 模拟面试（通过后再就业）、每日面试复盘、谈薪指导、企业内推、入职后持续答疑。

## 六、免费生态（线下引流 + 自学福利）

- 尚硅谷以**免费视频**著称：官网称 6000+ 小时教程、3 亿播放、全免费，覆盖 Java/Python/MySQL/STM32/PyTorch 等；
- 大模型相关免费课：LangChain、Spring AI、企业级大模型部署（Ollama/Xinference + Dify）、LangChain4J 医疗项目等；
- 模式：**免费视频获客 → 线下面授/实训收费**。对自学者，这些免费课本身就是高质量素材。

## 七、可直接偷走的 5 个设计

1. **多选一实战模板**：一套技术骨架 + N 个行业皮肤，标准化教学 + 差异化作品兼得；
2. **每个实战配"学习目标清单"**：让学员和评审都有明确验收标准；
3. **阶段考试卡点**：用考试强制阶段闭环，防止"跟着敲但没学会"；
4. **Harness / Loop 独立成模块**：从"会调框架"升级到"理解 Agent 工程"；
5. **免费内容做漏斗**：体系化免费视频既是口碑，也是学员预习/补课的抓手。
