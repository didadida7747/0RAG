# 03 · 达内 与 千锋教育

> 两家都是 2000 年代起步的老牌线下 IT/AI 培训机构，班型大、校企合作广。
> 达内 AI：<https://www.tedu.cn/ai/> ｜ 千锋 AI：<http://www.mobiletrain.org/zh-ai/>

## 一、达内：两套并行的 AI 课程体系

达内对不同基础给了两条路径，值得注意它"**分层产品线**"的做法。

### 路径 A：AI 大模型课程（3 阶段，偏应用/跨界）
| 阶段 | 主题 |
|---|---|
| 1 | **大模型提升研发效率**（用 AI 工具提效，入门门槛低） |
| 2 | **模型应用核心开发技术**（应用开发主体） |
| 3 | **大模型产品运营与创业变现**（产品、运营、变现） |

- 定位：不追求算法深度，主打"**会用 + 能做应用 + 懂运营变现**"，适合零基础、跨行业、想快速切入甚至创业的人；
- 借鉴点：把"**产品运营/变现**"作为独立阶段，是面向非技术岗位和创业者的差异化设计。

### 路径 B：AI 人工智能工程师（6 阶段，约 99 天，理论更厚）
| 阶段 | 主题 | 天数 |
|---|---|---|
| 1 | Python 核心语言 | 18 |
| 2 | 数据科学与商业智能 | 19 |
| 3 | 机器学习与数据挖掘 | 19 |
| 4 | 深度学习 | 20 |
| 5 | AIGC 与大模型 | 8 |
| 6 | 培优 · Python 全栈开发 | 15 |
| | **合计** | **99** |

- 这是传统"**数据科学 → 机器学习 → 深度学习 → 大模型**"的完整路径，理论体系更系统，大模型只放 8 天（作为前沿收口）；
- 与黑马/尚硅谷"以 Agent 为中心"不同，达内这条线**以数据/算法为地基**，再到大模型应用。

### 达内实践与就业机制
- 项目驱动式授课，官方称 1000 人教研团队、课程应用于 600 余所大学；
- 实训流程（以数据分析为例）：**项目立项 → 项目研发 → 项目汇报 → 作品包装 → 商业项目研发 → 作品合集整理**，强调"作品合集"；
- 参考价格约 2.1–2.4 万元（第三方口径，以官方为准）。

## 二、千锋教育：项目驱动 + 强就业闭环

### 课程与项目
- 项目定位"来自超一线大厂实际项目"：引入 **50+ 架构实战案例、50+ 大厂解决方案**；
- 代表项目：短视频推荐系统、智能聊天机器人、智能搜索引擎、知识图谱，"稍加改动即可用于生产"；
- AI 大模型方向要求**至少完成 3 个企业级项目**：基于 RAG 的智能问答系统、自动化报表生成工具、智能体开发项目；
- 实战项目占比官方称**超过 60%**。

### 师资与配套
- 10 余位资深架构师（含北科大博士），用讲师自编热门书籍作配套教材；
- 前沿课程"按月升级"，AI 产品线很广（大模型 Java、机器视觉、AI 测试/运维/嵌入式、鸿蒙生态等）。

### 班型 / 周期 / 学费（第三方口径）
| 班型 | 周期 | 学费（参考） |
|---|---|---|
| 基础班 | 4 个月 | 约 1.6 万元 |
| 就业班 | 6 个月 | 约 2.6 万元 |
| AI 机器视觉方向 | 4–5 个月 | 以官方为准 |

- 就业：与 5000+ 企业建立人才输送合作，含京东、美团、滴滴等及传统行业数字化部门。

## 三、两家 vs 黑马/尚硅谷：路线侧重对比

| | 达内（路径B）/千锋 | 黑马/尚硅谷 |
|---|---|---|
| 课程中心 | 数据科学/算法打地基，再到大模型 | 直接以 AI 应用/Agent 为中心 |
| 理论厚度 | 更厚（机器学习/深度学习占比高） | 更轻，快速进入项目 |
| 项目形态 | 大厂案例 + 作品合集 | 商用项目 + 多行业选一 |
| 适合 | 想把 AI 基础打牢、偏算法岗 | 想快速做应用、Agent/全栈岗 |

## 四、可直接偷走的设计

1. **分层产品线**：同一品牌下给"快速应用线"和"系统算法线"两条路径，让不同基础的人各取所需（达内）；
2. **把"产品运营/变现"做成模块**：面向创业和非技术岗位补一块差异化能力（达内路径A）；
3. **作品合集化**：实训按"立项→研发→汇报→包装→合集"走，把学习过程直接变成求职材料（达内）；
4. **硬性项目数量门槛**：明确"至少 N 个企业级项目 + 实战占比超 60%"，用数量约束保障动手量（千锋）；
5. **高频更新机制**：课程"按月/按季升级"，同步技术变化（千锋/黑马均有）。

> 对你的迁移：如果你想要更扎实的算法/数据科学底子（对西电电子信息方向也更对口），可参考达内 6 阶段把 ML/DL 补齐；若目标是快速做出 Agent 作品，则黑马/尚硅谷的"应用中心"路线更省力。
