# 01 · 黑马程序员：95 天 8 阶段（线下面授样板）

> 传智教育（A 股上市，股票代码 003032）旗下直营职教品牌。学科名 **《AI 应用与智能体开发》**，全程线下面授，主打"五位一体能力模型 + 95 天系统实战 + 全行业商用项目"。
> 官方学科页：<https://ai.itheima.com/> ｜ 路线图：<http://yun.itheima.com/subject/aiappmap/index.html>

## 一、顶层设计：五位一体能力模型

黑马先定义"企业要什么能力"，再倒推课程，五块能力闭环：

1. **指挥 AI 写软件**：Vibe Coding、Coze 零代码平台，Python + Java 双核全栈，用 AI 快速生成/调试代码；
2. **AI 智能体开发**：LangChain / LangGraph 多智能体编排、RAG 知识库、Milvus 向量库，搭企业数字员工、智能问答；
3. **软件工程化**：复刻大厂 DevOps——Docker 容器、微服务架构、性能调优，补"会 Demo 不会线上项目"的短板；
4. **行业业务解决方案**：金融、医疗、智能制造、电商、物流、智慧养老六大赛道，输出完整 AI 改造方案；
5. **传统软件智能化升级**：存量 Java 后台接入大模型/智能体改造，适配大量企业系统迭代岗位。

> 借鉴点：**先用"能力画像/岗位画像"定目标，再排课程**，而不是从知识点出发。每条能力都对应明确的"胜任岗位"。

## 三、实践安排怎么落地

- **10 大商用项目**：智能仓储、金融保险、智慧养老、物流 TMS、招聘知识图谱等，定位"脱敏生产级"，从需求调研→架构设计→数据库→部署运维完整复刻企业流程；
- **130+ 可复用行业方案**：配套标准化落地解决方案；
- **作品集导向**：结业可整理全套源码 + 架构文档作为求职作品集；
- **免费 GPU 机房**：13 座直营校区配 GPU 实训机房，微调/训练/向量库调试在校完成，免自学的算力租赁成本；
- **晚自习答疑 + 免费补学小班**：基础薄弱可补学，保障跟进度。

## 四、就业收口（营销口径，看机制不看数字）

- 机制：2000+ 合作企业、AI 专场双选会、跨城市内推、异地求职辅导；
- 岗位：AI Agent 开发、RAG 工程师、AI 中台 Java 开发、解决方案架构师等；
- 官方宣传：就业率 97%+、班级平均薪资约 11336 元、最高约 26800 元（**均为营销口径，需打折**）。

## 五、可直接偷走的 5 个设计

1. **能力模型先行**：用"五位一体 / 岗位画像"倒推课程，每个模块都能回答"学完能胜任什么岗"；
2. **零代码起步建立信心**：第 1 阶段先用 Coze 做出成品，再回头补 Python/Java，降低弃学率；
3. **2/3 时间做项目**：理论从简、实战从厚，项目按"单体→微服务→行业中台"逐级抬难度；
4. **每个项目都按生产流程走**：需求→架构→数据库→部署→文档，产出可直接进作品集；
5. **末端设独立就业周**：简历、题库、模拟面试作为独立阶段收口，而不是附带一提。

> 对你的迁移：自学时可照搬"阶段—天数—交付物"表，把 95 天脱产版拉长为课余 4–6 个月；做大创/竞赛时，按"单体可用 → 分布式/多 Agent → 行业方案"三级来设计作品深度。
