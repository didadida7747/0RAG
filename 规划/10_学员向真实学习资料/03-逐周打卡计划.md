# 03 · 逐周 / 逐日打卡计划（可直接执行）

> 主体：《AI 智能体开发半年学习计划（2026 版）》，原文 <https://blog.csdn.net/xingfuyusheng/article/details/163251866>
> 节奏：每周 10–15 小时（工作日每天 1–2h + 周末 3–5h）；**每周必须有"输入（学）+ 输出（做）"**，不欠"看了没动手"的债。
> 在校课余建议直接用 6 个月版；想冲刺可压缩到 3 个月（文末）。

## 半年主线一览

```
第1月 AI基础      第2月 Agent核心   第3月 框架工程化  第4月 RAG+记忆   第5月 项目实战   第6月 工程化+商业化
LLM原理          Agent架构        LangChain        RAG进阶          实战项目1        评估测试
Prompt工程       Tool Use         MCP协议          记忆系统          实战项目2        部署运维
API实践          RAG基础          多Agent协作       工作流编排        项目复盘         商业化
```

## 逐月逐周打卡表

### 第 1 月 · AI 基础与大模型原理
| 周 | 学习重点 | 本周交付物 |
|---|---|---|
| W1 | Transformer/Attention 直觉；Token、上下文窗口、Embedding；主流模型对比；温度/Top-P 采样 | 笔记《LLM 核心概念速通》+ 10 组不同参数对比实验 |
| W2 | Zero/Few-shot、CoT；结构化 Prompt；Self-consistency/ReAct/ToT；提示注入防护 | **个人 Prompt 模板库（≥5 场景）** + 博客一篇 |
| W3 | OpenAI/国内模型 API、流式输出；Function Calling 先了解；Token 计费 | **CLI 聊天工具**：可切模型、流式、多轮、费用统计 |
| W4 | 多模态（Vision/TTS/STT）；Agent/RAG/Code Interpreter 生态；框架定位；选定技术栈 | 本月复盘（见 04 清单） |

### 第 2 月 · 智能体核心开发
| 周 | 学习重点 | 本周交付物 |
|---|---|---|
| W1 | 感知→规划→行动→观察循环；ReAct；Plan-and-Execute；Agent vs Workflow；经典论文 | 架构笔记 + 论文速读卡片 |
| W2 | Function Calling 完整机制；工具类型与选择策略；失败恢复 | **工具增强 Assistant**：搜索/天气/计算器/代码执行，自主选工具、多步推理 |
| W3 | RAG 全流程；切分策略；Embedding；向量库（Chroma/Qdrant/Milvus）；MMR | **文档问答系统**：加载→切分→入库→问答并标注来源 |
| W4 | 失败模式（死循环/错工具/幻觉）；调试；LangSmith/Langfuse 可观测；版本 A/B | **完整单 Agent（工具+RAG）+ 开源到 GitHub** + 博客 |

### 第 3 月 · 框架与工程实践
| 周 | 学习重点 | 本周交付物 |
|---|---|---|
| W1–2 | LangChain / LlamaIndex 深入（组件、链、记忆、中间件） | LangChain 重构版 Agent |
| W3 | **MCP**：Host/Client/Server/Transport；开发 Server；生态；与 Function Calling 对比 | **MCP Server**：≥2 个 Tool + 1 个 Resource，并连接测试 |
| W4 | 多 Agent 模式（层级/平等/竞争）；通信；AutoGen/CrewAI/LangGraph/MetaGPT；避坑 | **多 Agent 协作系统**（软件团队或研究团队，可见通信过程） |

### 第 4 月 · RAG 深度与记忆系统
| 周 | 学习重点 | 本周交付物 |
|---|---|---|
| W1–2 | 混合检索、Reranking；HyDE/Multi-Query/Step-back；高级切分；多模态 RAG；RAGAS 评估 | **生产级 RAG**：混合检索 + HyDE + RAGAS 评估报告 + 基础/进阶对比 |
| W3 | Agent 记忆分类、短期/长期记忆、存储架构 | 带长期记忆的 Agent |
| W4 | 工作流编排（顺序/并行/分支/循环）；LangGraph 子图/持久化/流式/人工干预 | **自动研究助手**：计划→并行搜索→汇总→人工审核→补充→报告 |

### 第 5 月 · 项目实战（核心月）
| 周 | 项目 | 交付标准 |
|---|---|---|
| W1–2 | **项目 1：智能客服 Agent**（Chroma/Qdrant + Streamlit/Gradio/Chainlit + 多模型对比） | 可运行 Demo + GitHub（README/架构图/部署文档）+ 复盘博客 |
| W3–4 | **项目 2：个人知识助手**（多源接入、增量更新、标源问答、知识图谱、复习卡片、长期记忆） | 可运行应用 + GitHub + **部署上线** + 复盘博客 |

### 第 6 月 · 工程化、部署与商业化
| 周 | 重点 | 交付物 |
|---|---|---|
| W1 | 评估与测试（任务成功率/准确率/成本/延迟） | 自动评估脚本与报告 |
| W2 | 部署运维（Docker/Linux/CI-CD/监控） | 线上可访问的服务 |
| W3 | 成本优化与性能调优（缓存/模型选型/并发） | 优化前后对比数据 |
| W4 | 商业化与个人品牌 | 作品集主页 + Demo 视频 + 求职/接单就绪 |

## 配套博客输出（每周 1 篇，共 11 篇）

LLM 概念速通 → Prompt 结构化 → 第一个 Agent → MCP 详解 → 多 Agent 设计 → RAG 检索 5 技巧 → 记忆系统 → 客服 Agent 复盘 → 知识助手复盘 → 成本优化 → 半年总结。
> 写博客不是为教别人，而是逼自己把理解讲清楚；同时积累内容资产。

## 三个可选时间版本

| 版本 | 周期 | 适合 | 调整方式 |
|---|---|---|---|
| 半年版（上表） | 6 个月，每周 10–15h | 在校课余，**推荐** | 按表执行 |
| 3 个月冲刺版 | 12 周，全职/高密度 | 假期、停课、转行 | 每月内容压到 2 周，项目月保留 |
| 12 周（在职 18 周） | 12–18 周 | 有编程基础、在职 | 见 Java 转 AI 路线 PDF，Phase1–4 各延到 3 周 |

**3 个月版每周小目标（可打印贴桌面）**
- 第 1–4 周：LLM/Prompt/API/单 Agent（做出 CLI 工具 + 工具助手）；
- 第 5–8 周：RAG + LangGraph + MCP（做出知识库问答 + MCP Server）；
- 第 9 周：认识微调、准备 10–20 条数据；
- 第 10 周：完成第一次简单微调并判断效果；
- 第 11 周：确定成品方向、搭核心框架；
- 第 12 周：完善成品、测试、准备展示素材。
