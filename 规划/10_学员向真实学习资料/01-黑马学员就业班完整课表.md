# 01 · 黑马学员就业班完整课表（阶段-天数-技术点-项目）

> 来源：黑马学员路线图官方页 <https://aiapp.itheima.com/itheima/aiappzly.html>（线下面授就业班）。
> 这是学员实际执行的课表，精确到每阶段的**课时、技术点数量、学习目标、主讲内容和配套项目**。
> （阶段一为零代码入门 9 天，见 08 分类；本篇重点展开核心技术阶段二/四/五。）

## 阶段二 · RAG 智能体开发就业班（10 天，48 个技术点）

**学习目标（学员达标线）**
1. 掌握 LangChain 核心组件；2. 能用 LangChain 开发智能体；3. 掌握 LangGraph 核心概念；4. 能用 LangGraph 编排复杂 Agent 工作流；5. 掌握向量库 Milvus；6. 掌握 RAG 原理与实现；7. 从零搭一个 Multi-Agent 智能客服；8. 掌握 Linux 常用命令并用 Docker 部署 AI 应用。

**主讲内容（四大模块，共 48 个技术点）**

| 模块 | 技术点清单 |
|---|---|
| **1. LangChain** | ①认识 LangChain ②Models ③Messages ④Prompts ⑤Tools ⑥Memory ⑦Runtime ⑧Middleware ⑨MCP ⑩MultiAgent |
| **2. RAG** | ①RAG 原理 ②Document Loader ③Text Splitter ④Embedding Model ⑤Vector Store ⑥Milvus ⑦Retrievers ⑧RAG 多种模式 ⑨RAG 系统评估 |
| **3. LangGraph** | ①概述 ②核心概念 ③流程编排 ④MultiInput 工作流 ⑤Sequence 工作流 ⑥ConditionalGraph ⑦LoopingGraph ⑧ReAct Agent ⑨Evaluator-optimizer ⑩Parallelization ⑪Routing ⑫项目案例 |
| **4. AI 项目部署** | Linux：概述安装/常用命令/软件安装/项目部署（4）；Docker：介绍安装/快速入门/常见命令/操作案例/数据卷与目录挂载/Dockerfile/自定义镜像/容器网络/项目部署/Compose（13） |

> 学员阶段产出：一个 **Multi-Agent 智能客服** + 一个 **RAG 企业问答**，并能部署到 Linux/Docker。

## 阶段四 · AI 工程化-微服务智能体实战（20 天，3 个项目）

### 项目 1：智链云途（物流，106 技术点）
- 基于 Spring Cloud Alibaba 的生产级物流系统，AI 与物流核心业务深度融合；
- **14 个解决方案**：AI 身份认证风控、运费计算智能体、BERT 物品识别、组织机构识别、路线成本因子分析、LangGraph 智能推荐网点、XGBoost 快递员调度、运单智能合并、智能调度验证、模型持续训练（RabbitMQ+MongoDB）、微服务治理（Nacos/Feign/Gateway/Seata/XXL-JOB/幂等）、高可用与流量保护（Sentinel/Redis 多级缓存/分布式锁）、消息驱动与数据同步（RabbitMQ/Canal）、分布式搜索（ElasticSearch）；
- **19 个知识点**：快速熟悉新项目、Gateway 统一鉴权、JWT 双 Token、支付/运费微服务、Redisson 分布式锁、Neo4j 路线规划、物流智能调度、MongoDB 作业范围、Caffeine+Redis 多级缓存、缓存三大问题、AI 登录风控、LangChain 运费智能体、BERT 训练部署、LangGraph 多节点推荐、XGBoost 调度与合并、调度回退重排、模型训练闭环。

### 项目 2：AI 云岚到家（家政 O2O，142 技术点）
- 四端协同（用户小程序 / 服务 APP / 机构 PC / 运营 PC），含下单、智能派单、抢单、支付结算、LBS 追踪；
- **22 个解决方案**：缓存一致性、异构数据同步、MQ 可靠性、ES 全文检索、用户定位、用户认证、文件存储、支付对接、接口安全、状态机状态管理、订单快照、取消订单、分库分表、海量分页、多线程任务、分布式调度、分布式锁、秒杀抢购、分布式事务、NLP 智能助手、ES 搜索附近、撮合匹配；
- **15 个知识点**：熟悉项目、运营/认证/首页/优惠券/订单/支付模块、AI 在线预约助手、系统优化、秒杀抢券/抢单、派单调度、项目运维、就业指导、多行业项目指导。

### 项目 3：AI 四方保险（保险 SaaS，77 技术点）
- 面向保险销售的 SaaS 平台，前后端分离 + Spring Cloud Alibaba；
- **7 大核心模块**：保险发布、保费计算、收益试算、保司承保、合同订单、随心配服务、扣款计划（覆盖核保、承保、理赔全链路）。

## 阶段五 · 企业级项目智能化升级（12 天，2 个项目）

### 项目 4：智聘云图（招聘知识图谱，96 技术点）
- 基于 LLM 的招聘知识图谱检索系统，Java 后端 + Python AI 服务双端；技术栈 ES/Redis/Kafka/Flink/LangGraph/vLLM；
- **13 个解决方案**：职位数据清洗标准化、LLM 职位要素抽取、招聘知识图谱构建、搜索意图识别、图谱增强检索、分域检索与相关性排序、搜索 badcase 优化、结果可解释性、Kafka+Flink 近实时同步、隐私脱敏、LoRA SFT + DPO 微调、vLLM 服务化部署（KV Cache/FP16/降级）、Redis 缓存加速；
- **14 个知识点**：项目与环境、职位建模、数据清洗、要素抽取与 Prompt、图谱构建、LangGraph 图谱智能体、意图识别、ES 检索、图谱增强与兜底、实时检索链路、微调与评估、服务化部署压测、前端联调、效果优化与面试讲解。

### 项目 5：AgentCenter（智能体服务中台，12 技术点 + 1 次测验）
- 基于 LangChain/LangGraph 的智能体中台，业务系统对接实现智能化；核心项目为"**天机学堂 AI 助手**"（智能课程推荐、学习咨询、自动交易）；
- **9 条学习目标**：业务理解与框架集成、核心对话（新建/流式/停止）、PostgreSQL checkpointer 会话管理、Tool Calling 课程查询与卡片、对接 EduRAG 与课程推荐、开发 AgentCenter 中台与业务对接、6 种智能体架构与 LangGraph 路由、A2A 协议独立智能体、MCP Client/Server；
- 核心技术：Prompt 工程、Tool Calling、Routing Agent、A2A 协议、MCP 协议。

## 课表总览（学员视角的时间线）

| 阶段 | 天数 | 主题 | 阶段项目 |
