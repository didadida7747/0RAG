# 04 · 国际认证与纳米学位：要背书/督学时再付费

> 这类资料的价值 = **成体系路径 + 真实项目评审 + 可写进简历的证书 + 英文技术环境**。
> 如果你只是要学会做 Agent，[01-厦大](01-厦大林子雨-AI编程与智能体开发-成套免费.md) + [02-B站](02-B站成套系统教程.md) + LangChain Academy（免费）已经足够；**要证书、要督学、要冲外企/海外岗，再考虑付费**。

## 速选表

| 项目 | 提供方 | 形态 | 花费 | 亮点 |
|---|---|---|---|---|
| Certified Agent Engineer + Learning Paths | LangChain 官方 | 认证 + 学习路径 | Academy 课免费，认证咨询官方 | **最对口的 Agent 工程师认证** |
| Agentic AI Engineer（ND901） | Udacity | 纳米学位 | 付费（常有助学金/分期） | 项目制、导师评审、就业向 |
| Generative AI with LangChain | Coursera × Packt | 3 门课专项 | 订阅制，可**旁听/申请助学金** | 系统、可只学单门 |
| Agentic AI: Developing AI Agents | edX × IBM | 3 周短课 | 可免费旁听，证书付费 | 轻量、IBM 背书 |
| AI Agents Bootcamp 2026 | Udemy | 长视频实战课 | 常打折到几十元 | **付费里性价比最高** |

## 1. LangChain 官方：Certified Agent Engineer（最对口）

- 入口：<https://enterprise-hub.langchain.com/education>
- **Certified Agent Engineer（新）**：覆盖 Agent 开发全生命周期——构建、测试、部署、监控，是框架官方出的能力认证。
- **Learning Paths**：如 *Deep Agents Deep Dive*，教会规划、用子代理、操作文件系统的复杂 Agent（核心概念 + 架构模式 + 动手演示）。
- **免费先行**：LangChain Academy（<https://academy.langchain.com>）的 *Introduction to LangChain*、*LangGraph Essentials* 免费，从第一个 Agent 到多智能体系统。**不管考不考证，这两门都建议刷。**

## 2. Udacity · Agentic AI Engineer with LangChain and LangGraph（ND901）

- <https://www.udacity.com/course/agentic-ai-engineer-with-langchain-and-langgraph--nd901>
- 面向有 Python 基础的开发者：LangChain 基础（提示模板、链、记忆、单工具 Agent）→ 多工具规划、自我批评循环、部署 → RAG 接入外部知识、长期记忆。
- 价值：**项目制 + 导师/评审 + 纳米学位证书**，适合要就业背书、需要有人盯进度的人；价格偏高，学生看优惠/助学金。

## 3. Coursera · Generative AI with LangChain（Packt 专项）

- 3 门课系列：从生成式 AI 与 LangChain 如何让模型完成复杂任务（含 Agent 决策），到工作流、工具构建、部署智能系统。
- 可**免费旁听（audit）**看内容，或申请助学金；适合想系统学但预算有限、且不急于拿证的人。

## 4. edX · IBM: Agentic AI: Developing AI Agents

- <https://www.edx.org/learn/artificial-intelligence/ibm-agentic-ai-developing-ai-agents>
- 中级、约 3 周、自-paced；动手实验教工具调用、chaining、LCEL 工作流、内置 Agent，做"会推理、能行动"的应用。
- 可免费旁听、证书付费；**时间短、IBM 背书**，适合快速补一块权威经历。

## 5. Udemy · AI Agents Bootcamp 2026（付费性价比之王）

- <https://www.udemy.com/course/ai-agents-bootcamp-build-with-langchain-rag-langflow-gpt/>
- Python 生产级 Agent：LangChain 1.x、LangGraph、RAG、MCP、Human-in-the-loop、LangSmith 评估、FastAPI。
- Udemy 常年打折（原价高、折后常几十元人民币），**不想花大钱又想要一套完整跟练视频**选它；缺点是无证书含金量、靠自律。

## 怎么选（结合你的情况）

- **零预算、学技术**：LangChain Academy（免费）+ 厦大讲义 + B 站 152 集 → 做项目，完全够；
- **要简历证书、预算有限**：edX IBM（可旁听，拿证便宜）或 Coursera 申请助学金；
- **要系统督学 + 项目评审 + 海外/外企岗**：Udacity ND901 或 LangChain 官方认证；
- **只想花小钱买套完整跟练**：Udemy 打折时入 Bootcamp。

> 提醒：证书是敲门砖不是能力本身。**招聘/竞赛真正看的是你 GitHub 上能跑的 Agent 项目**——无论选哪条路，都要把本库 [06_代码实验室](../06_代码实验室/README.md) 的东西做成可演示作品。
