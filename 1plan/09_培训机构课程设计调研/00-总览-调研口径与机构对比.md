# 09 · 培训机构课程设计调研：总览

> 目的不是帮你挑机构报名，而是**拆解成熟培训机构"怎么组织课程、怎么安排实践、怎么收口到就业"**——这套被市场反复打磨的教学设计，对你自学、做大创/竞赛项目、甚至搭建自己的课程/创业产品，都是现成的参照系。

## 一、调研口径

- **方向**：承接上文，聚焦 **AI / 大模型应用开发 / AI Agent（智能体）** 方向的课程；
- **机构**：选 6 家最有代表性、课程大纲公开的——
  - **线下重实训**：黑马程序员、尚硅谷、达内、千锋教育；
  - **线上体系课/训练营**：慕课网、极客时间；
- **资料来源**：各机构官方课程页 / 学科介绍 / 教材官网（抓取于 2026.10）；
- **可信度提醒**：就业率、平均薪资、"需求暴增 543%""缺口 500 万"等均为**机构营销口径**，看结构和方法即可，具体数字要打折。

## 三、两类模式的本质差异

| 维度 | 线下机构（黑马/尚硅谷/达内/千锋） | 线上体系课（慕课网/极客时间） |
|---|---|---|
| 核心交付 | 面授 + 班级氛围 + 强制作息 + 实训机房 | 成体系视频 + 作业/点评 + 答疑社群 |
| 买的主要是 | **督学、环境、项目陪跑、就业渠道** | **结构化内容 + 时间灵活 + 单价低** |
| 实践安排 | 大量"脱敏生产级项目"，分组/分行业实战 | 手敲代码量 + 1–2 个大项目 + 在线 IDE |
| 周期/价格 | 3–6 个月脱产，普遍 1.6–2.8 万 | 几百到数千，可碎片化学 |
| 适合 | 零基础转行、需要被推着走 | 有自制力、在校/在职、预算有限 |

> 一个反常识点：**两类机构的技术内容高度同质**（Python→LangChain/LangGraph→RAG→MCP→微调→部署）。真正拉开差距的不是"教什么知识点"，而是**项目实战的密度、工程化深度和就业收口**——这正是本调研要偷的东西。

## 四、怎么用这份调研

1. **先看 [05-共性规律](05-共性规律与可借鉴教学设计.md)**：六家殊途同归的"课程组织 + 实践安排"方法论，是最高浓度的部分；
2. 再按需要细读单家：**想抄"阶段+天数+项目表"**看黑马（[01](01-黑马程序员-95天8阶段.md)）；**想抄"多行业选一的实战设计"**看尚硅谷（[02](02-尚硅谷-10阶段与多选实战.md)）；
3. 把可迁移的结构，落到你自己的学习计划 / 大创项目 / 竞赛作品 / 创业课程设计里。

## 五、阅读时的三个"过滤器"

1. **把营销话术和课程结构分开**：薪资、就业率、风口数字忽略；阶段划分、项目清单、考核与交付物才是干货；
2. **项目要看"完整度"而非数量**：是否含需求→架构→数据库→部署→文档全流程，是否可整理成作品集；
3. **时效**：2026 年的课都在讲 MCP / LangGraph / 多智能体 / 微调部署；只讲老版 Chain、不提工程化的体系已偏旧。
