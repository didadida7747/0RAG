# 05 · 共性规律：六家机构殊途同归的教学设计

> 把黑马、尚硅谷、达内、千锋、慕课网、极客时间叠在一起，差异主要在营销和班型，**骨架几乎一致**。本篇提炼这套"被市场验证的模板"，并给出可直接复用的培养表。

## 一、课程组织：5 条共性

1. **岗位/能力画像倒推课程**：先定义"胜任什么岗、要什么能力"，再排知识点（黑马五位一体、各家"能力画像→参考薪资"）；
2. **零代码/低门槛起步**：第 1 阶段先用 Coze / Vibe Coding 做出成品建立信心，再补 Python/Java，降低弃学率；
3. **统一技术主线**：大模型/Prompt → RAG → Agent（LangChain/LangGraph）→ MCP → 微调 → 部署工程化，六家高度重合；
4. **理论从简、实战占大头**：普遍 60% 以上时间在做项目，难度按"**单体 → 微服务/多智能体 → 行业中台/综合方案**"三级抬升；
5. **高频迭代**：课程按月/按季更新，同步框架与协议变化。

## 二、实践安排：6 条共性

1. **项目驱动 + 全流程**：脱敏生产级项目，完整走需求→架构→数据库→部署→文档，不做孤立小 Demo；
2. **"多行业 N 选一"模板**：一套技术骨架 + N 个行业皮肤，教学标准化 + 作品差异化（尚硅谷最典型）；
3. **阶段考核卡点**：用考试/答辩强制阶段闭环，过了才进下一阶段；
4. **量化交付**：代码行数、项目数、案例数明确（如慕课 7 万行、2 项目、16 案例）；
5. **作品集导向**：源码 + 架构文档可直接整理成求职/竞赛材料；
6. **工程化与评估必教**：Docker、FastAPI、Git、Linux、日志监控，以及 RAGAS 等效果评估；环境/算力用 GPU 机房、在线 IDE、Ollama 本地模型兜底。

## 三、就业收口：3 条共性

1. **独立的就业阶段**：简历打磨、高频题库、1V1 模拟面试（通过后再投）；
2. **渠道**：企业合作、专场双选会、内推；
3. **谈薪 + 入职后答疑**，把服务延伸到上岗初期。

## 四、一张可直接复用的"通用培养模板"

> 把六家共性固化成一张表。脱产可压到 3 个月，在校课余拉长到 4–6 个月；天数按比例缩放即可。

| 模块 | 目标 | 关键内容 | 交付物（验收） |
|---|---|---|---|
| 0 · 入门（约 10%） | 建立 AI 思维与信心 | 大模型基础、提示词、Coze/Vibe Coding | 1 个零代码 Agent |
| 1 · 编程与工程基座（约 15%） | 能独立写前后端、搭环境 | Python、Linux、Git、Docker、FastAPI、数据库、前端 Vue | 1 个小型全栈应用 |
| 2 · RAG（约 15%） | 做企业知识库 | 文档处理、向量库、检索/重排序、RAGAS 评估 | 1 个可溯源 RAG 问答系统 |
| 3 · Agent / 多智能体（约 25%） | 做复杂智能体 | LangChain/LangGraph、工具、记忆、Harness/Loop、MCP、多 Agent | 1 个多轮对话/多智能体项目 |
| 4 · 工程化与行业项目（约 25%） | 达到生产级 | 微服务、部署、监控、行业方案、多行业选一 | 1 个行业级完整项目 + 文档 |
| 5 · 微调/进阶（约 5%） | 私有化落地 | LoRA 微调、vLLM 部署（按需） | 1 个私有化模型 Demo |
| 6 · 收口（约 5%） | 作品 + 面试 | 作品集整理、题库、模拟答辩 | GitHub 作品集 + 路演 |

> 核心配比记忆点：**约 2/3 时间动手做项目，每个阶段都有可验收交付物，最后统一收口成作品集。**

## 五、迁移到你自己的场景

### 1）个人自学
- 照搬上表做"阶段—周数—交付物"打卡表；每阶段设自测（可复用本库 [00_方法与路线/04-自测卷](../00_方法与路线/04-自测卷.md)）；
- 先用 Coze 做出成品再补理论；**一次主攻一套资源，别囤课**。

### 2）大创 / 竞赛
- 作品深度按三级设计：**单体可用（初赛）→ 多 Agent/分布式（复赛）→ 行业解决方案 + 评估数据（决赛）**；
- 用"多行业选一"思路找差异化场景（如西电校园、陕西本地行业）；
- 必补 RAGAS/评测与工程化，评委更认"可评估、可落地"，而非炫技。

### 3）创业 / 做课程产品
- **能力画像倒推**课程，把成果量化（项目数、代码量、作品集）；
- **免费内容做漏斗**（尚硅谷模式）+ **轻督学服务**（训练营模式：班主任、作业、社群、退款保障）；
- 内容期与服务期分离，拉长用户生命周期；课程按季度迭代。

## 六、一句话总结

> 成熟机构真正在卖的不是"知识点"，而是一套**"低门槛起步 → 高密度项目实战 → 阶段考核 → 作品集 + 就业收口"的确定性流程**。
> 你完全可以零成本复制这套流程的"结构"，把它用在自学、竞赛和创业上——**区别只在于，机构用商业服务帮你坚持，而你要自己当自己的班主任。**
