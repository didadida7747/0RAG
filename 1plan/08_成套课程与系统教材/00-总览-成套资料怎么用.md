## 推荐主线（和本库源码精读拼一条完整路径）

> 本库 01–04 章是"**读现成 Agent 源码**"，08 是"**被系统带着学一遍**"。两者不是二选一，是先后咬合：

1. **先建体系（08）**：跟厦大林子雨 MOOC/讲义过一遍 9 章 → 大模型、AI 编程三阶段、LangChain、LangGraph 的骨架立起来；
2. **再读源码（本库 01–03 章）**：带着骨架去精读 Claude Code / Gemini CLI / Aider 的 harness，理解"框架背后在解决什么问题"；
3. **动手闭环（本库 06 代码实验室）**：跑通 `toy_agent_harness.py` + 做完练习题，再用 LangGraph 做一个带 RAG / MCP 的小项目；
4. **持续追更（05 资源地图）**：上岗/竞赛之后靠它跟新版本、新框架。

> 时间预算参考：全职 2–4 周；在校课余 4–6 周。**第 3 步的"做出一个能演示的 Agent"是真正的交付物**，可直接用于西电竞赛、大创、简历。

## 三条避坑约定

1. **警惕"748集 / 7天从小白到大神 / 学完即就业"标题**：多为把多个短课拼接、或训练营引流。判断成套质量只看一条——**有没有清晰递进的章节目录、每章有没有回顾与作业**（见 [02](02-B站成套系统教程.md) 的辨别标准）。
2. **版本比书名短命**：所有 LangChain/LangGraph/MCP 的具体 API 以官方文档为准；2026 年的资料重点学**设计模式与工程思维**，别背函数签名。
3. **别陷入"收藏=学会"**：成套资料一次只主攻一套，跑通代码再换下一套；同时囤三套视频 = 一套都学不完。
