## 为什么把它列为头号

这是本分类里**唯一"四件套配齐"的成套资料**，而且全部免费、高校官方、中文、体系闭环：

1. **MOOC 视频**：林子雨本人主讲，已发布到 B 站，跟着课堂走；
2. **讲义 PPT（PDF）**：9 章完整，可逐章下载（即下面的分章直链）；
3. **上机实验手册 + 教学大纲**：不是只讲概念，有可上机的实践任务；
4. **全套代码与提示词**：教材里的代码/提示词官方直接给可复制版本，不用手抄。

对西电电子信息/计算机方向的你：内容从**大模型基础 → AI 编程三阶段（提示词 / 规范 / 流程驱动）→ 智能体 → LangChain → LangGraph**，深浅适中，既能当入门主线，也能当大创/竞赛的技术底稿。

## 怎么学（建议节奏）

1. **视频 + 讲义并行**：看一章 MOOC，对照该章 PDF，把代码在本机跑一遍；
2. **必做上机实验手册**：第 3 章环境搭建务必亲手过一遍（虚拟环境、IDE/AI 工具）；
3. **重心压在第 8、9 章**：LangChain / LangGraph 是做项目的核心，配合本库 [06_代码实验室](../06_代码实验室/README.md) 的 `toy_agent_harness.py` 对照理解；
4. **学完即产出**：用 LangGraph 做一个带 RAG 或 MCP 工具的小 Agent（如西电校园问答、课程资料检索），作为大创/竞赛/简历作品。

## 和本库的咬合

- 这套教材给你**骨架和操作**；本库 [01_ClaudeCode_Harness精读](../01_ClaudeCode_Harness精读/00-总览-一个Agent-Harness的解剖图.md) 给你**工业级真实 Agent 的设计深度**。
- 建议顺序：**本套 9 章 → 本库 01/02 章源码精读 → 06 章动手**。读完教材再看源码，会明显顺很多。
