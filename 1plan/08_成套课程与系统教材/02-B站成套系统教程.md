## 怎么判断一个"全套教程"值不值得跟

1. **看合集目录，不看标题**：优质成套有清晰递进（环境→框架→工具→协议→项目），且**每章有回顾/作业**；标题写"748集/7天大神/学完即就业"但目录是一堆重复短课拼接的，直接弃。
2. **看技术时效**：3 个月内发布、用 LangChain 1.x / LangGraph / MCP 等当前技术栈；还在只讲老版 Chain、不提 MCP 的偏旧。
3. **看是否可离线/低成本**：优先支持 Ollama 本地模型或国产低价 API 的，别一开始就被绑死在昂贵 API 上。
4. **看简介与评论**：放 GitHub 源码/文档、评论区技术追问作者接得住的更靠谱；满屏"求私/带带"或引流训练营的快跑。

## 学习姿势

- **边看边敲**：每段代码在本机复现，卡壳先看评论区/官方文档，不要只囤进度；
- **跟到模块 6 就开工**：用学到的 MCP/RAG 做一个自己的 Agent，再回头看 7–10 补工程化；
- **视频搭骨架，本库补深度**：跟完一套后，回本库 [01_ClaudeCode_Harness精读](../01_ClaudeCode_Harness精读/00-总览-一个Agent-Harness的解剖图.md) 看工业级 Agent 为什么这么设计。
