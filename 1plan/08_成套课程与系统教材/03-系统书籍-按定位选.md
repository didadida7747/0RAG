# 03 · 系统书籍：按"定位"选，别照单全买

## A. 主线教材（二选一，跟着做）

### 《AI Agent 智能体开发》—— 陈宇 / 清华社
- 出版 2026.04，定价 89.8 元，ISBN 9787302712664；**官方提供课件、代码**。
- 定位：标准教材写法，适合"上课式"系统学习，配套资料全，自学和做课程设计都顺手。

### 《AI Agent 开发实战：MCP+A2A+LangGraph》—— 人邮
- 出版 2026.01，定价 99.8 元，320 页。
- 定位：**工程实战导向**，直接对齐 MCP（工具协议）、A2A（智能体协作）、LangGraph（编排）这套当前主流工程栈，"从基础理论到工程落地"。
- 选择建议：想要**课件/课堂感**选陈宇那本；想**紧贴工程协议、做能上线的东西**选这本。

## B. 架构与设计模式（进阶，二选一）

### 《Agentic 智能体设计模式》—— Antonio Gulli / 清华社
- 作者是谷歌资深工程总监（CTO 办公室），30 余年 AI 搜索与云计算经验。
- 核心：**21 种可复用设计模式**，按金字塔分三层递进——
  - 第 1–7 章：从提示链到多智能体协作，搭可靠的智能体流水线；
  - 第 8–11 章：记忆管理、目标设定与监控，自我纠错与长程规划；
  - 第 12–21 章：知识检索到探索发现，打通"原型 → 生产"。
- 适合：已经能写 Agent、但总觉得是"玩具 Demo"，想要**可复用架构范式**的人。

### 《Agent 设计模式：图解可复用智能体架构》—— 黄佳 / 人邮
- 2026.02，豆瓣 9.2。图解风格，把智能体架构拆成看得懂的图，和 Gulli 那本互为补充：这本更易读，那本更全更深。

## C. 底层工程思维

### 《从零构建 AI Agent》
- 不讲"用哪个框架"，而是沿**六层系统架构**，从智能体底层认知 → 工具调用 → 多智能体协作，给一条主线和一整套工程思维。
- 适合：被各种框架/短课搞得"知识是散的"，想真正理解机制、不被单一框架绑死的人。与本库"读源码"路线气质最合。

## D. 专项（项目需要再买）

- **黄佳《大模型应用开发 RAG 实战课》**（人邮 2025.05，豆瓣 9.2）：如果你的项目是知识库问答/检索增强，这本是中文里口碑最高的 RAG 专项。
- **宝玉《图解 Skill》**（人邮 2026.05，豆瓣 7.6）：做 Agent Skills / 可复用技能时参考。

## 给西电学生的选书建议

1. **入门阶段**：别急着买书——[01-厦大林子雨](01-厦大林子雨-AI编程与智能体开发-成套免费.md) 免费讲义 + MOOC 已够搭骨架；
2. **要做项目/想精读**：入 1 本主线（推荐《AI Agent 开发实战 MCP+A2A+LangGraph》）；
3. **冲竞赛/工程质量**：再加 1 本模式（图解易读选黄佳，求全选 Gulli）；
4. **RAG 是核心再单独补**黄佳 RAG 专项。
5. 读书时**代码必须上机**，并对照本库 [06_代码实验室](../06_代码实验室/README.md) 验证；只画线不写代码，书等于白读。

> 时效提醒：书出版后框架仍在更新，把书当"原理与架构"载体，具体函数/参数以官方文档为准。
